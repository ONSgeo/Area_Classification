# `docs` folder overview

Documentation for the area classification pipeline can be found in this folder as Markdown files (`.md`). Browse the Markdown files in this folder for information on different aspects of the project. 

## Contents
These documents are split into three folders: 
- `analytical_quality_assurance` - this folder details the aqa plan, assumptions and caveats and data log.
These files document how this project meets organisational [guidance on producing
quality analysis for HM Government projects][aqua-book]. [aqua-book]: https://www.gov.uk/government/publications/the-aqua-book-guidance-on-producing-quality-analysis-for-government
- `specifications` - this folder contains specifications for all sections of the main pipeline including an overview of each section, requirements and limitations
- `user_guide` - this folder details the structure of the repo, naming conventions and instructions on how to use pytest
