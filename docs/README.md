# `docs` folder overview

All documentation for the project should be included in this folder in either reStructuredText or Markdown files.

## Analytical quality assurance (AQA)

All analytical quality assurance (AQA) documents can be found in the `docs/analytical_quality_assurance` folder.
These files document how this project meets organisational [guidance on producing
quality analysis for HM Government projects][aqua-book].

[aqua-book]: https://www.gov.uk/government/publications/the-aqua-book-guidance-on-producing-quality-analysis-for-government
