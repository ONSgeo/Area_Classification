## Project structure layout

The cookiecutter template generated for each project will follow this folder structure:

```shell
.
├── area_classification/
│   └── area_classification/
│       ├── example_modules/
│       │   ├── __init__.py
│       │   └── example_module.py
│       ├── __init__.py
│       ├── example_config.yml
│       └── run_pipeline.py
└── ...
```
