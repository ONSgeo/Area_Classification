# `tests` folder overview

All tests for the functions defined in the `area_classification` folder are stored here. The structure of the folders in here should also align to the folder structure within `area_classification` for ease of understanding which function is being tested.

## Usage
Each test checks that the function is working as expected using mock data, the tests can be ran by running each test script.
